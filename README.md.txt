# Hospital Readmission Prediction

## Project Overview
This project uses Machine Learning to predict hospital readmission risk using the Diabetes 130-US Hospitals dataset.

## Objectives
- Clean and preprocess the dataset.
- Perform feature encoding.
- Train machine learning models.
- Compare model performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Models Used
1. Logistic Regression
2. Decision Tree
3. Random Forest
